# 数据报表需求文档

> 日期：2026-08-02
> 目的：为平台增加用量报表界面，展示会话数、Token 用量、费用等核心指标，帮助用户了解自身使用情况，帮助管理员掌握平台整体运行状况。

## 1. 背景与目标

目前平台已有简单的仪表盘（`DashboardPage`，仅显示会话/记忆/技能/智能体数量卡片），缺少对**使用量**的量化展示。用户无法回答"我这个月用了多少 token、花了多少钱、哪个智能体用得最多"这类问题。

目标：

- 为用户提供个人用量报表（会话、消息、Token、费用趋势）。
- 为管理员提供平台级报表（活跃用户、全局 Token、模型分布）。
- 复用已有的 `token_usage_daily` 表结构，补齐数据写入链路。

## 2. 数据现状盘点

| 数据源 | 现状 | 可用性 |
|---|---|---|
| `token_usage_daily` 表（user_id + date + model 维度，含 prompt/completion/total tokens、request_count、cost_usd） | 表结构已建好，但**没有任何代码写入**，目前是空表 | 需补写入链路 |
| `messages.token_usage`（JSONB） | 每条助手消息记录 token 用量 | 可用，但逐行聚合慢，适合做明细核对 |
| `traces.total_tokens` | 每次 Agent 执行的总 token | 可用 |
| `sessions` / `messages` | 会话数、消息数、时间戳齐全 | 可用 |
| `llm_models` | 模型名称、提供商 | 用于维度展示 |

**结论**：报表查询以 `token_usage_daily` 为主（预聚合，快），会话/消息指标直接查 `sessions`/`messages` 聚合。必须先实现 `token_usage_daily` 的写入（在 AgentLoop 每次 LLM 调用完成后 upsert），否则报表无数据。

## 3. 角色与范围

| 角色 | 可见范围 |
|---|---|
| 普通用户 | 自己的用量数据（走 RLS / `user_id` 过滤） |
| 管理员 | 平台全局数据 + 按用户/租户下钻 |

## 4. 功能需求

### 4.1 个人报表页（新增路由 `/usage`）

**顶部指标卡（当前时间范围内）：**

| 指标 | 说明 |
|---|---|
| 会话数 | 范围内创建的会话总数，含较上周期环比 |
| 消息数 | 用户消息 + 助手消息条数 |
| Token 总量 | prompt + completion 合计 |
| 请求次数 | LLM 请求总次数 |

> 不展示费用：本期不考虑模型价格，`cost_usd` 字段保留但恒为 0，前端不出现费用指标。

**趋势图（折线/柱状）：**

- Token 用量按日趋势（可切换 prompt / completion / total）
- 会话数按日趋势
- 时间范围切换：**默认今天**，可选 近 7 天 / 近 30 天 / 自定义

**分布图：**

- 按模型分布（饼图或横向条形图）：各模型 token 占比
- 按智能体分布（横向条形图）：各 Agent 的会话数 / token 占比

**明细表：**

- 按日 × 模型的用量明细（日期、模型、prompt/completion/total、请求数），支持导出 CSV

### 4.2 管理员全局视图（同一 `/usage` 页，不独立路由）

`/usage` 页内按角色切换：管理员在页面上方看到"我的 / 全局"视图切换（Segmented），切到全局后展示：

- 活跃用户数（范围内有过会话的用户数，按日趋势）
- 全局 Token 用量趋势
- 用户排行 Top N（按 token 用量）
- 按渠道来源分布（Web / 飞书等，`channel_session_mappings`）

普通用户不渲染切换器，仅看自己的数据。

### 4.3 入口

- 侧边栏新增"用量统计"菜单项（图标 `BarChartOutlined`），位于"仪表盘"下方，路由 `/usage`。

> 后端接口设计与技术要点见 [02-技术方案.md](02-技术方案.md)。

## 5. 分期规划

**MVP（第一期）：**

1. `token_usage_daily` 写入链路（最重要，否则无数据）
2. 个人报表页 `/usage`：指标卡 + Token/会话趋势图 + 按模型分布 + 明细表（默认时间范围：今天）
3. 管理员在同一页内切换"我的 / 全局"视图
4. 侧边栏入口

**第二期：**

1. 管理员全局视图增强：用户排行、渠道分布、活跃用户趋势
2. CSV 导出
3. 环比对比
4. 费用展示（待引入模型价格配置后再启用）

**非目标（本期不做）：**

- 实时报表（秒级刷新）
- 用量告警 / 配额限制
- 自定义报表搭建
