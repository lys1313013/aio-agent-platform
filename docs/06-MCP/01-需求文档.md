# MCP (Model Context Protocol) 需求文档

> 本文档定义 AIO Agent Platform 的 MCP 协议集成需求，覆盖功能、安全、运维和用户体验。

---

## 1. 概述

### 1.1 目标

通过 MCP 协议接入外部工具生态，使 Agent 能够调用第三方 MCP Server 提供的工具（如 GitHub、Notion、数据库、文件系统等），扩展 Agent 能力边界。

### 1.2 核心原则

- **无差异体验**：MCP 工具与内置工具在 Agent 视角下无差异，LLM 无需区分工具来源
- **管理员管控**：MCP Server 的增删改查仅限管理员操作，普通用户只读
- **错误隔离**：单个 MCP Server 崩溃不影响 Agent 主进程和其他 Server
- **安全性**：MCP Server 凭证（API Key、Token）加密存储，不暴露给 Agent

### 1.3 传输协议

| 协议 | 描述 | 适用场景 | 状态 |
|------|------|---------|------|
| **SSE** | Server-Sent Events 长连接 | 旧版 MCP Server、需要持久连接 | ✅ 已实现 |
| **Streamable HTTP** | HTTP POST + 可选 SSE 流式响应 | 新版 MCP Server、无状态/有状态均可 | ✅ 已实现 |
| ~~stdio~~ | ~~本地进程 stdin/stdout~~ | ~~本地开发~~ | ❌ 不支持 |
