# 项目文档索引

模块化组织：`NN-主题/` 按编号排序，模块内文档按「需求文档 → 技术方案 →（可选）实现详解」排列。

**文档类型：**
- **需求文档** — 做什么：背景、功能、边界、验收标准
- **技术方案** — 怎么做：架构、数据模型、实现细节
- **实现详解** — 深入代码级细节（仅多智能体模块使用）

## 阅读顺序

先读 `00-产品需求文档` 与 `01-技术栈` 建立全局认识，再按需进入各模块。
