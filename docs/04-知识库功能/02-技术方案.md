## 一、系统架构

### 1.1 整体架构

```
┌──────────────┐    ┌────────────────────┐    ┌─────────────────┐
│  Agent Chat  │───▶│  knowledge_        │───▶│  RAGFlow Server │
│  (LLM 调用)  │    │  retrieval tool    │    │  /dify/retrieval│
└──────────────┘    └────────────────────┘    └─────────────────┘
        │                    │
        │                    │ 查询 agent_knowledge_bases
        │                    ▼
        │            ┌──────────────────┐
        │            │  knowledge_bases │──▶ dataset_id
        │            └──────────────────┘
        │                    │
        │                    │ 读取全局配置
        ▼                    ▼
  ┌──────────┐    ┌──────────────────┐
  │ Agent 表  │    │  system_config   │──▶ base_url, api_key
  └──────────┘    └──────────────────┘
```

### 1.2 核心设计决策

| 决策点 | 方案 | 理由 |
|--------|------|------|
| 全局配置存储 | `system_config` 表（系统级单例） | 简单直接，符合"默认知识库"语义；后台可修改 |
| Agent 绑定粒度 | `knowledge_bases` 资源表 + `agent_knowledge_bases` 关联表 | 可管理系统内浏览/管理数据集，Agent 可选绑定多个 |
| 工具注册方式 | 内置工具 `knowledge_retrieval` | 复用现有工具注册机制，与 MCP 工具、记忆工具保持一致 |

## 二、外部接口规范

### 2.1 RAGFlow `/dify/retrieval` 接口

RAGFlow 实现了 Dify 外部知识库 API 规范（v0.12.0+）。

#### 请求

```http
POST {base_url}/api/v1/dify/retrieval
Authorization: Bearer {api_key}
Content-Type: application/json

{
  "knowledge_id": "<dataset_id>",
  "query": "用户的问题",
  "retrieval_setting": {
    "top_k": 5,
    "score_threshold": 0.3
  }
}
```

#### 响应

```json
{
  "records": [
    {
      "content": "chunk text...",
      "score": 0.87,
      "title": "文档标题",
      "metadata": { ... }
    }
  ]
}
```

#### 注意事项

- 多知识库时需对每个 `dataset_id` 分别请求，然后合并结果
- 空结果返回 `{"records": []}`
- 参考：[Dify External Knowledge API](https://docs.dify.ai/en/use-dify/knowledge/external-knowledge-api)

## 四、后端实现细节

### 4.1 RAGFlow 客户端

**文件**：`backend/src/aio_agent/knowledge/ragflow_client.py`

```python
import httpx
import asyncio
from typing import Any

async def retrieve(
    base_url: str,
    api_key: str,
    dataset_ids: list[str],
    query: str,
    top_k: int = 5,
    score_threshold: float = 0.3,
    timeout: float = 30.0,
) -> list[dict[str, Any]]:
    """对每个 dataset_id 并发调用 RAGFlow /dify/retrieval，合并结果。"""

    async def _retrieve_one(dataset_id: str) -> list[dict]:
        url = f"{base_url.rstrip('/')}/api/v1/dify/retrieval"
        headers = {
            "Authorization": f"Bearer {api_key}",
            "Content-Type": "application/json",
        }
        payload = {
            "knowledge_id": dataset_id,
            "query": query,
            "retrieval_setting": {
                "top_k": top_k,
                "score_threshold": score_threshold,
            },
        }
        async with httpx.AsyncClient(timeout=timeout) as client:
            resp = await client.post(url, json=payload, headers=headers)
            resp.raise_for_status()
            data = resp.json()
            records = data.get("records", [])
            # 附加 dataset_id 来源标识
            for r in records:
                r["dataset_id"] = dataset_id
            return records

    # 并发查询所有 dataset
    tasks = [_retrieve_one(did) for did in dataset_ids]
    results = await asyncio.gather(*tasks, return_exceptions=True)

    all_records = []
    for r in results:
        if isinstance(r, list):
            all_records.extend(r)

    # 按 score 降序排列，取 top_k
    all_records.sort(key=lambda x: x.get("score", 0), reverse=True)
    return all_records[:top_k]
```

**设计说明**：
- 使用 `asyncio.gather` 并发查询多个知识库，提升性能
- 使用 `return_exceptions=True` 避免单个知识库失败导致整体失败
- 按 `score` 降序排列，确保最相关的结果排在前面

### 4.4 工具处理器

**文件**：`backend/src/aio_agent/knowledge/handlers.py`

```python
from __future__ import annotations

import structlog
from sqlalchemy import select
from aio_agent.core.context import current_agent_id
from aio_agent.db.connection import get_session_factory
from aio_agent.db.models import (
    Agent, AgentKnowledgeBase, KnowledgeBase, SystemConfig,
)
from aio_agent.knowledge.ragflow_client import retrieve

logger = structlog.get_logger()

async def handle_knowledge_retrieval(
    arguments: dict, user_id: str, session_id: str, **kwargs
) -> str:
    """处理 knowledge_retrieval 工具调用"""
    
    query = arguments.get("query", "")
    top_k = min(arguments.get("top_k", 5), 20)

    if not query:
        return "Error: query parameter is required"

    agent_id = current_agent_id.get(None)
    if not agent_id:
        return "Error: no agent context available"

    factory = get_session_factory()
    async with factory() as db:
        # 1. 查询 agent 绑定的知识库 → dataset_ids
        kb_result = await db.execute(
            select(KnowledgeBase.dataset_id)
            .join(AgentKnowledgeBase, AgentKnowledgeBase.knowledge_base_id == KnowledgeBase.id)
            .where(
                AgentKnowledgeBase.agent_id == agent_id,
                KnowledgeBase.is_active == True,
            )
        )
        dataset_ids = [r[0] for r in kb_result.all()]
        if not dataset_ids:
            return "No knowledge bases configured for this agent."

        # 2. 读取 system_config 中的 RAGFlow 配置
        config_result = await db.execute(
            select(SystemConfig).where(
                SystemConfig.key.in_(["ragflow_base_url", "ragflow_api_key"])
            )
        )
        config = {r.key: r.value for r in config_result.scalars().all()}
        base_url = config.get("ragflow_base_url", "")
        api_key = config.get("ragflow_api_key", "")

    if not base_url or not api_key:
        return "Error: RAGFlow is not configured. Please set base_url and api_key in admin settings."

    # 3. 调用 RAGFlow
    try:
        records = await retrieve(
            base_url=base_url,
            api_key=api_key,
            dataset_ids=dataset_ids,
            query=query,
            top_k=top_k,
        )
    except Exception as e:
        logger.error("ragflow_retrieval_failed", error=str(e))
        return f"Error retrieving from knowledge base: {e}"

    if not records:
        return "No relevant information found in the knowledge base."

    # 4. 格式化输出
    parts = [f"Found {len(records)} relevant chunks from knowledge base:\n"]
    for i, rec in enumerate(records, 1):
        title = rec.get("title", "Unknown")
        score = rec.get("score", 0)
        content = rec.get("content", "")
        parts.append(
            f"{i}. [{title}] (score: {score:.2f})\n"
            f"   {content[:1000]}"  # 截断过长内容
        )
    return "\n\n".join(parts)


KNOWLEDGE_HANDLERS = {
    "knowledge_retrieval": handle_knowledge_retrieval,
}
```

**设计说明**：
- 使用 `top_k = min(..., 20)` 限制最大返回数量，防止过大响应
- 截断每个 chunk 到 1000 字符，避免返回过长内容
- 使用 `structlog` 记录错误日志，便于排查问题
