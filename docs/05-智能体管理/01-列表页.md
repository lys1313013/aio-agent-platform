## 智能体卡片

### 卡片内容

| 区域 | 内容 | 说明 |
|------|------|------|
| 图标 | emoji 表情 | 大字号居中展示 |
| 名称 | 智能体名称 | 粗体 |
| 描述 | 一行描述 | 最多 2 行，超出截断 |
| 标签 | 模型名 / 工具数 / 技能数 | 底部标签行，紧凑排列 |

### 卡片交互

- **点击卡片** → 直接进入该智能体的对话页面 (`/agents/:id/chat`)
- **hover 效果** → 轻微上浮 + 阴影加深
- **所有者 / 管理员额外元素**：
  - 右上角显示状态标签（启用/禁用）
  - 右下角 `···` 菜单：编辑、删除

### 空状态

无智能体时显示空状态插图 + 提示文案：
- 管理员："还没有智能体，点击上方按钮创建第一个"
- 普通用户："还没有智能体，点击上方按钮创建你的第一个智能体"

## 创建智能体

### 权限

所有用户均可创建智能体，创建后拥有完整配置权限。

| | 普通用户 | 管理员 |
|---|---------|--------|
| 创建 | ✓ | ✓ |
| 配置（提示词、模型、工具、技能、子智能体） | ✓（自己创建的） | ✓（所有） |
| 删除 | 只能删除自己创建的 | 可删除所有 |

### 创建表单（弹窗）

| 字段 | 控件 | 必填 | 说明 |
|------|------|------|------|
| 名称 | Input | ✓ | 如：编程助手、文档专家 |
| 图标 | Select（emoji 选择器） | ✓ | 10 个预设 emoji |
| 描述 | Input | | 一句话描述 |
| 系统提示词 | TextArea + 模板选择 | | 留空使用默认 |
| 欢迎语 | TextArea | | 新会话开场白 |
| 模型 | Select | | 选择 LLM 模型，留空使用全局默认 |
| 温度 | InputNumber (0~2) | | 推理温度，留空使用默认 |
| 工具 | Checkbox.Group | | 勾选启用的工具 |
| 技能 | 多选 Select | | 搜索并绑定技能 |
| 子智能体 | 多选 Select | | 关联子智能体用于任务委派 |
| 启用状态 | Switch | | 创建后是否立即可用 |

### 创建成功后

- 弹窗关闭
- 新卡片出现在列表中
- 自动跳转到该智能体的对话页面

## 数据可见性

| 用户类型 | 可见的智能体 |
|---------|-------------|
| 普通用户 | 自己创建的 + 管理员创建的已启用智能体 |
| 管理员 | 所有智能体 |

> 需要后端 `agents` 表新增 `owner_id` 字段记录创建者。
