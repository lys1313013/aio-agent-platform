# 自定义远程工具（HTTP 工具）需求文档

> 本文档定义 AIO Agent Platform 的"自定义远程工具"功能需求。
> 允许管理员通过 Web UI 配置任意 REST API 端点为 Agent 可调用工具，无需编写代码，无需 MCP 协议。
> 技术设计见同目录 [02-技术方案.md](02-技术方案.md)。

---

## 1. 概述

### 1.1 背景与动机

当前系统接入外部服务有两种方式:

| 方式 | 优点 | 缺点 |
|------|------|------|
| **硬编码工具** | 灵活、可控 | 每接一个 API 都要改代码、发版 |
| **MCP 协议** | 标准、生态丰富 | 要求对方实现 MCP Server,很多企业 API 不提供 |

**缺口**:大量第三方服务(JIRA、企业微信、飞书、内部中台、BI 平台、工单系统等)只暴露普通 REST API,既没有 MCP Server,也不值得为它们各写一段硬编码。

**目标**:让管理员在 Web UI 填一张表,就能把一个 REST API 端点注册为 Agent 工具,Agent 调用时自动发 HTTP 请求、解析响应、返回结果。

### 1.2 核心原则

- **零代码接入**:管理员通过配置完成,不需要写 Python/不需要发版
- **与内置工具无差异**:LLM 视角下,远程工具与内置工具完全一致(function calling)
- **安全可控**:管理员才能配置;敏感信息(凭证)加密存储;支持 URL 白名单
- **灵活映射**:支持 URL 模板变量、请求体模板、Header 注入、响应提取

### 1.3 与 MCP 的关系

| 维度 | MCP 工具 | 自定义远程工具 |
|------|----------|----------------|
| 对方要求 | 必须实现 MCP 协议 | 任意 REST/HTTP API |
| 工具发现 | 自动(list_tools) | 管理员手动配置 |
| 参数 Schema | 自动获取 | 管理员手动定义 |
| 适用场景 | 对方提供 MCP Server | 对方只提供普通 API |
| 复杂度 | 低(配置 URL 即可) | 中(需配置参数映射) |

两者互补,共存于同一 Agent 工具选择面板。

## 2. 功能需求

### 2.1 远程工具管理(管理员)

| 编号 | 需求 | 优先级 | 状态 |
|------|------|--------|------|
| F-HTTP-01 | 管理员可通过 Web UI 创建远程工具 | P0 | ⬜ |
| F-HTTP-02 | 配置工具名称(name,唯一标识,LLM 可见) | P0 | ⬜ |
| F-HTTP-03 | 配置工具描述(description,LLM 可见,指导 LLM 何时调用) | P0 | ⬜ |
| F-HTTP-04 | 配置 HTTP Method(GET / POST / PUT / DELETE / PATCH) | P0 | ⬜ |
| F-HTTP-05 | 配置 URL 模板,支持路径变量(如 `https://api.example.com/users/{user_id}`) | P0 | ⬜ |
| F-HTTP-06 | 配置 Query 参数映射(哪些工具参数放到 URL query string) | P1 | ⬜ |
| F-HTTP-07 | 配置请求头(静态 Header + 认证 Header) | P0 | ⬜ |
| F-HTTP-08 | 配置请求体模板(JSON Template,支持变量插值) | P0 | ⬜ |
| F-HTTP-09 | 配置参数 Schema(JSON Schema,告诉 LLM 需要传什么参数) | P0 | ⬜ |
| F-HTTP-10 | 配置响应提取(Response JSONPath,只把有用部分返回给 LLM) | P1 | ⬜ |
| F-HTTP-11 | 配置超时时间(5-600 秒) | P1 | ⬜ |
| F-HTTP-12 | 编辑远程工具配置 | P0 | ⬜ |
| F-HTTP-13 | 删除远程工具 | P0 | ⬜ |
| F-HTTP-14 | 启用/禁用远程工具 | P1 | ⬜ |
| F-HTTP-15 | 测试调用(管理员填完参数后,填测试值,实际发一次请求验证) | P1 | ⬜ |
| F-HTTP-16 | 导入/导出(批量导入 OpenAPI/Swagger 定义自动生成工具) | P3 | ⬜ |

### 2.2 认证配置

| 编号 | 需求 | 优先级 | 状态 |
|------|------|--------|------|
| F-AUTH-01 | 支持 None(无认证) | P0 | ⬜ |
| F-AUTH-02 | 支持 Bearer Token(在 Header 注入 `Authorization: Bearer xxx`) | P0 | ⬜ |
| F-AUTH-03 | 支持 API Key(自定义 Header 名,如 `X-API-Key: xxx`) | P0 | ⬜ |
| F-AUTH-04 | 支持 Basic Auth(用户名+密码,Base64 编码) | P1 | ⬜ |
| F-AUTH-05 | 支持自定义 Header 注入任意静态凭证 | P0 | ⬜ |
| F-AUTH-06 | 凭证加密存储(DB 中加密,日志/UI 脱敏) | P1 | ⬜ |
| F-AUTH-07 | 支持 OAuth2 Client Credentials(自动获取 access_token) | P2 | ⬜ |

### 2.3 工具注册与调用

| 编号 | 需求 | 优先级 | 状态 |
|------|------|--------|------|
| F-CALL-01 | 远程工具创建后自动注册到 ToolRegistry | P0 | ⬜ |
| F-CALL-02 | 远程工具自动转换为 OpenAI function calling 格式 | P0 | ⬜ |
| F-CALL-03 | Agent 调用时,根据配置构建 HTTP 请求并发出 | P0 | ⬜ |
| F-CALL-04 | 响应 JSON 序列化为字符串返回给 Agent | P0 | ⬜ |
| F-CALL-05 | HTTP 错误(非 2xx)返回结构化错误信息给 Agent | P0 | ⬜ |
| F-CALL-06 | 超时处理(返回超时错误信息) | P0 | ⬜ |
| F-CALL-07 | 输出截断(超过 10,000 字符自动截断,复用 executor 逻辑) | P0 | ⬜ |
| F-CALL-08 | 工具调用记录审计日志(工具名、参数、URL、响应码、耗时) | P2 | ⬜ |
| F-CALL-09 | URL 路径变量从工具参数中提取并替换 | P0 | ⬜ |
| F-CALL-10 | Query 参数从工具参数中提取并附加到 URL | P1 | ⬜ |
| F-CALL-11 | 请求体模板变量从工具参数中插值 | P0 | ⬜ |

### 2.4 Agent 工具选择

| 编号 | 需求 | 优先级 | 状态 |
|------|------|--------|------|
| F-SEL-01 | 远程工具在 Agent 配置侧边栏的"工具"区域显示 | P0 | ⬜ |
| F-SEL-02 | 远程工具带特殊标识(如"HTTP"标签,区分于内置工具) | P1 | ⬜ |
| F-SEL-03 | 支持单个远程工具的启用/禁用 | P0 | ⬜ |
| F-SEL-04 | 远程工具与内置工具、MCP 工具共存于 Agent 的 enabled_tools | P0 | ⬜ |

## 3. 安全需求

### 3.1 访问控制

| 编号 | 需求 | 优先级 | 状态 |
|------|------|--------|------|
| S-SEC-01 | 远程工具 CRUD API 仅限管理员 | P0 | ⬜ |
| S-SEC-02 | 普通用户可通过 tools API 查看远程工具列表(只读) | P1 | ⬜ |
| S-SEC-03 | 凭证在 UI 中脱敏显示(只显示 `****`,不显示原文) | P1 | ⬜ |
| S-SEC-04 | 凭证不暴露给 Agent(LLM 无法读取认证信息) | P0 | ⬜ |

### 3.2 网络安全

| 编号 | 需求 | 优先级 | 状态 |
|------|------|--------|------|
| S-NET-01 | 支持 HTTPS 端点 | P0 | ⬜ |
| S-NET-02 | URL 白名单(管理员配置允许访问的域名列表) | P2 | ⬜ |
| S-NET-03 | 禁止访问内网地址(127.0.0.1、10.x、192.168.x 等,可配置放开) | P1 | ⬜ |
| S-NET-04 | 防止 SSRF(服务端请求伪造,限制重定向次数) | P1 | ⬜ |

### 3.3 数据安全

| 编号 | 需求 | 优先级 | 状态 |
|------|------|--------|------|
| S-DATA-01 | 远程 API 返回内容在注入 Prompt 前标记信任边界 | P3 | ⬜ |
| S-DATA-02 | 防止 Prompt 注入(远程 API 返回可能含恶意指令) | P2 | ⬜ |
| S-DATA-03 | 响应内容大小限制(防止巨型响应占满上下文) | P1 | ⬜ |
