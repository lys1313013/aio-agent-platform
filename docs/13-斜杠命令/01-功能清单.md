# 斜杠命令功能清单

> 参考来源：OpenClaw 斜杠命令、Hermes Agent 命令体系、飞书生态机器人命令实践。
> 本文档只列举功能，作为斜杠命令的统一维护清单。实现方案另立文档。
>
> 通用约定：
> - 消息以 `/` 开头即视为命令，由服务端拦截解析，不进入 Agent 对话
> - 未知命令降级为普通消息发送给 Agent
> - 确定性命令（查状态、列列表）直接返回结果，零 token 消耗
> - Web 聊天页输入 `/` 时弹出候选菜单自动补全；飞书渠道因无原生命令菜单，以 `/help` 卡片和交互式消息卡片（按钮/下拉）替代
> - 除标注「管理员」外，所有命令普通用户可用；命令效果默认只作用于当前会话

## 1. 帮助与发现

| 命令 | 功能 |
|---|---|
| `/help` | 显示命令帮助摘要，按分组列出 |
| `/commands` | 列出全部可用命令（含动态生成的技能命令），支持分页 |
| `/whoami` | 显示当前用户 ID、租户、所在会话信息 |

## 2. 会话管理

| 命令 | 功能 |
|---|---|
| `/new`（别名 `/reset`） | 清空当前上下文，开启新会话 |
| `/sessions` | 列出我的历史会话 |
| `/switch <id>` | 切换到指定会话 |
| `/resume [id]` | 恢复上次会话或指定会话的上下文 |
| `/rename <标题>` | 重命名当前会话 |
| `/delete <id>` | 删除指定会话 |
| `/export [格式]` | 导出会话记录（Markdown / HTML / JSON） |
| `/branch`（别名 `/fork`） | 从当前消息分叉出新会话，保留此前上下文 |

## 3. 上下文与用量

| 命令 | 功能 |
|---|---|
| `/context`（别名 `/ctx`） | 显示上下文占用：token 估算、各消息/工具结果占比 |
| `/compact` | 立即压缩上下文，生成摘要释放 token |
| `/usage` | 显示本会话 token 用量与模型调用次数统计 |
| `/clear-tools` | 清除历史工具调用结果，保留对话文本 |

## 4. 运行控制

| 命令 | 功能 |
|---|---|
| `/stop` | 中断当前正在执行的 Agent 任务 |
| `/retry` | 重新生成上一条回答 |
| `/undo` | 撤回上一轮对话（用户消息 + Agent 回复） |
| `/steer <提示>` | 在 Agent 运行中途注入提示，不打断执行 |
| `/queue <消息>`（别名 `/q`） | 消息排队，等当前任务结束后依次执行 |
| `/background <任务>` | 将任务转为后台异步执行，完成后推送通知 |
| `/tasks` | 列出当前活跃/最近的后台任务与子任务 |

## 5. 模型与生成行为

| 命令 | 功能 |
|---|---|
| `/model [名称]` | 查看或切换当前会话使用的模型 |
| `/think <级别>` | 设置思考深度（off / low / medium / high） |
| `/fast on\|off` | 切换快速模式（优先速度，降低思考开销） |
| `/verbose on\|off` | 开关详细输出（工具调用过程、参数明细） |
| `/reasoning on\|off` | 开关推理过程（思维链）流式展示 |
| `/trace on\|off` | 开关调试追踪（Langfuse trace 链接回显） |

## 6. 智能体与委派

| 命令 | 功能 |
|---|---|
| `/agents` | 列出我可用的智能体 |
| `/agent <名称>` | 切换当前会话绑定的智能体 |
| `/delegate <智能体> <任务>` | 显式将任务委派给指定子智能体 |
| `/subagents` | 列出当前运行中的子智能体及其状态 |
| `/kill <id\|all>` | 终止一个或全部运行中的子智能体 |
| `/send <id> <消息>` | 向运行中的子智能体追加指令 |

## 7. 工具与技能

| 命令 | 功能 |
|---|---|
| `/tools` | 列出当前 Agent 可用工具（内置 / MCP / 远程工具） |
| `/skills` | 列出已安装技能 |
| `/skill <名称> [输入]` | 直接运行指定技能，不经过模型规划 |
| `/<技能名>` | 已安装技能自动注册为动态斜杠命令 |
| `/mcp` | 查看 MCP 服务器连接状态与工具清单 |
| `/reload-mcp`（管理员） | 热重载 MCP 配置 |
| `/reload-skills` | 热重载技能目录 |

## 8. 记忆与知识库

| 命令 | 功能 |
|---|---|
| `/memory` | 查看当前用户长期记忆列表 |
| `/remember <内容>` | 手动写入一条长期记忆 |
| `/forget <id\|关键词>` | 删除指定记忆 |
| `/knowledge <问题>` | 直接检索知识库并返回结果，不生成对话 |
| `/portrait` | 查看 Agent 对当前用户的画像摘要 |

## 9. 沙箱与工作区

| 命令 | 功能 |
|---|---|
| `/sandbox` | 查看沙箱状态（容器、运行时长、资源占用） |
| `/files` | 列出当前工作区沙箱文件 |
| `/ws list` | 列出我的工作区 |
| `/ws use <slug>` | 切换当前会话工作区 |
| `/restart-sandbox` | 重建当前会话的沙箱容器 |

## 10. 定时任务

| 命令 | 功能 |
|---|---|
| `/cron list` | 列出我的定时任务 |
| `/cron create <表达式> <任务>` | 创建定时任务 |
| `/cron pause <id>` / `/cron resume <id>` | 暂停 / 恢复定时任务 |
| `/cron delete <id>` | 删除定时任务 |
| `/loop <间隔> <任务>` | 在当前会话内循环执行某提示词 |

## 11. 确认与权限

| 命令 | 功能 |
|---|---|
| `/approve <id>` | 通过待确认操作（等效于点击确认卡片按钮） |
| `/deny <id>` | 拒绝待确认操作 |
| `/yolo on\|off` | 开关免确认模式（高危操作自动放行，仅本人会话生效） |

## 12. 系统与诊断

| 命令 | 功能 |
|---|---|
| `/status` | 系统状态：在线模型、沙箱、MCP、渠道连接、队列概况 |
| `/doctor`（管理员） | 环境自检：数据库、对象存储、沙箱镜像、LLM 连通性 |
| `/config show` | 查看当前会话级配置 |
| `/config set <键> <值>`（管理员） | 修改运行时配置 |
| `/restart`（管理员） | 重启后端服务 |
| `/diagnostics`（管理员） | 生成诊断报告（日志摘要、错误统计）供排障 |

## 13. 飞书渠道特有

| 命令 | 功能 |
|---|---|
| `/help`（卡片版） | 返回交互式消息卡片，按钮/下拉替代手打命令 |
| `/focus` | 将群话题绑定到独立会话 |
| `/unfocus` | 解除当前话题绑定 |
| `/btw <问题>` | 侧边提问，不污染当前会话上下文 |
| `/bind` | 绑定飞书账号与平台账号 |
| `/mute` / `/unmute` | 群聊中临时屏蔽 / 恢复机器人响应 |

## 14. 交互增强（Web 端）

| 功能 | 说明 |
|---|---|
| 输入 `/` 弹出命令菜单 | 按分组展示，支持模糊搜索与参数提示 |
| 命令执行结果以系统消息展示 | 与 Agent 回复样式区分，不占上下文 |
| 动态命令 | 技能、远程工具自动出现在候选菜单 |
| 权限过滤 | 菜单只显示当前用户有权使用的命令 |
