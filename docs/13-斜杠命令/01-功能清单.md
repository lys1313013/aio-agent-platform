# 斜杠命令功能清单

> 参考来源：OpenClaw 斜杠命令、Hermes Agent 命令体系、飞书生态机器人命令实践。
> 状态图例：✅ 已实现 · ⏳ 待实现。
> 实现方案见 `02-实现方案.md`。

## 通用约定

- 消息以 `/` 开头即视为命令，由服务端拦截解析，**不进入 Agent 对话**
- **Web 端**：已知命令执行，结果以 `role=system` 消息持久化到会话历史（不进 LLM 上下文，不污染对话）；未知命令返回提示，不报错
- **飞书渠道**：已知命令执行并直接回复文本；未知命令**降级为普通消息**发送给 Agent
- 确定性命令（查状态、列列表）直接返回结果，零 token 消耗
- Web 聊天页输入 `/` 弹出候选菜单自动补全；飞书渠道无原生命令菜单，以 `/help` 文本列表替代（交互式卡片待实现）
- 除标注「管理员」外，所有命令普通用户可用；命令效果默认只作用于当前会话

## 已实现命令

### 1. 帮助与发现

| 命令 | 功能 | 状态 |
|---|---|---|
| `/help` | 显示命令帮助摘要，按分组列出（Web 与飞书均可用，飞书为纯文本列表） | ✅ |
| `/commands` | 列出全部可用命令（含动态生成的技能命令） | ✅ |
| `/whoami` | 显示当前用户 ID、租户、角色、会话数与记忆数 | ✅ |

### 2. 会话管理

| 命令 | 功能 | 状态 |
|---|---|---|
| `/new`（别名 `/reset`、`/clear`） | 清空当前上下文，开启新会话（Web 端自动切换新会话） | ✅ |
| `/sessions` | 列出我的历史会话（最近 20 条） | ✅ |
| `/rename <标题>` | 重命名当前会话 | ✅ |
| `/delete <id>` | 删除指定会话 | ✅ |
| `/switch <id>` / `/resume [id]` | 切换到指定 / 恢复上次会话 | ⏳ |
| `/export [格式]` | 导出会话记录（Markdown / HTML / JSON） | ⏳ |
| `/branch`（别名 `/fork`） | 从当前消息分叉出新会话 | ⏳ |

### 3. 上下文与用量

| 命令 | 功能 | 状态 |
|---|---|---|
| `/context`（别名 `/ctx`） | 显示上下文占用：token 估算、各消息/工具结果占比 | ⏳ |
| `/compact` | 立即压缩上下文，生成摘要释放 token | ⏳ |
| `/usage` | 显示本会话 token 用量与模型调用次数统计 | ⏳ |

### 4. 运行控制

| 命令 | 功能 | 状态 |
|---|---|---|
| `/stop` | 中断当前正在生成的回复（Web 端中断 SSE 流并返回确认） | ✅ |
| `/retry` | 重新生成上一条回答 | ⏳ |
| `/undo` | 撤回上一轮对话（用户消息 + Agent 回复） | ⏳ |

### 5. 会话模型

| 命令 | 功能 | 状态 |
|---|---|---|
| `/model` | 查看当前会话使用的模型与可用模型列表（**只读**，切换待实现） | ✅ |

### 6. 智能体与委派

| 命令 | 功能 | 状态 |
|---|---|---|
| `/agents` | 列出我可用的智能体（标注当前绑定） | ✅ |
| `/agent <名称>` | 切换当前会话绑定的智能体 | ✅ |
| `/delegate <智能体> <任务>` | 显式将任务委派给指定子智能体 | ⏳ |

### 7. 工具与技能

| 命令 | 功能 | 状态 |
|---|---|---|
| `/skills` | 列出已安装技能 | ✅ |
| `/skill <名称> [输入]` | 展开指定技能内容供直接使用 | ✅ |
| `/<技能名>` | 已安装技能自动注册为动态斜杠命令（内容同 `/skill`） | ✅ |
| `/tools` | 列出当前 Agent 可用工具（内置 / MCP / 远程工具） | ⏳ |
| `/mcp` / `/reload-mcp`（管理员） | 查看 MCP 状态 / 热重载配置 | ⏳ |
| `/reload-skills` | 热重载技能目录 | ⏳ |

### 8. 记忆与知识库

| 命令 | 功能 | 状态 |
|---|---|---|
| `/memory` | 查看当前用户长期记忆列表 | ✅ |
| `/remember <内容>` | 手动写入一条长期记忆（L2 层） | ✅ |
| `/forget <id>` | 删除指定记忆（按 ID；按关键词检索删除待实现） | ✅ |
| `/knowledge <问题>` | 直接检索当前会话智能体绑定的知识库并返回结果 | ✅ |
| `/portrait` | 查看 Agent 对当前用户的画像摘要 | ✅ |

### 9. 工作区

| 命令 | 功能 | 状态 |
|---|---|---|
| `/ws list` | 列出我的工作区（标注当前） | ✅ |
| `/ws use <slug>` | 切换当前会话工作区 | ✅ |
| `/files` | 列出当前工作区文件 | ⏳ |

### 10. 定时任务

| 命令 | 功能 | 状态 |
|---|---|---|
| `/cron list` | 列出我的定时任务 | ✅ |
| `/cron create <表达式> <任务>` | 创建定时任务（表达式支持引号，如 `/cron create '0 9 * * *' 日报`） | ✅ |
| `/cron pause <id>` / `/cron resume <id>` | 暂停 / 恢复定时任务 | ✅ |
| `/cron delete <id>` | 删除定时任务 | ✅ |
| `/loop <间隔> <任务>` | 在当前会话内循环执行某提示词 | ⏳ |

### 11. 确认与权限

| 命令 | 功能 | 状态 |
|---|---|---|
| `/approve [id]` | 通过待确认操作；不带 id 时列出本会话待确认项 | ✅ |
| `/deny [id]` | 拒绝待确认操作；不带 id 时列出本会话待确认项 | ✅ |
| `/yolo on\|off` | 开关免确认模式 | ⏳ |

### 12. 系统状态

| 命令 | 功能 | 状态 |
|---|---|---|
| `/status` | 系统状态：在线模型、MCP、渠道连接、队列概况 | ⏳ |

### 13. 飞书渠道特有

| 命令 | 功能 | 状态 |
|---|---|---|
| `/help` | 从统一命令注册表生成的分组文本列表（卡片版待实现） | ✅ |
| `/bind` | 绑定飞书账号与平台账号 | ✅ |
| `/new`（`/clear`、`/reset` 等效） | 开启新会话（走渠道专用逻辑，切换会话映射） | ✅ |
| 其他已实现命令 | `/memory`、`/cron`、`/skills`、`/agents` 等全部统一命令在飞书均可用，结果直接文本回复 | ✅ |
| `/focus` / `/unfocus` | 将群话题绑定到独立会话 / 解除绑定 | ⏳ |
| `/btw <问题>` | 侧边提问，不污染当前会话上下文 | ⏳ |
| `/mute` / `/unmute` | 群聊中临时屏蔽 / 恢复机器人响应 | ⏳ |

### 14. 交互增强（Web 端）

| 功能 | 说明 | 状态 |
|---|---|---|
| 输入 `/` 弹出命令菜单 | 按分组展示，支持前缀模糊搜索、上下键导航、Tab/Enter 补全与参数占位提示 | ✅ |
| 命令结果以系统消息展示 | 与 Agent 回复样式区分（浅色卡片、`系` 头像），不占上下文 | ✅ |
| 动态命令 | 技能自动出现在候选菜单与 `/commands` 中 | ✅ |
| 权限过滤 | 菜单只显示当前用户有权使用的命令 | ✅ |
