# AIO Agent Platform — 多智能体技术实现文档

> 本文档定义多智能体系统的技术方案、数据模型、接口设计和实现细节。

---

## 1. 架构概览

### 1.1 设计原则

- **工具化委派**：委派建模为 `delegate_task` 工具调用，复用现有 ReAct 循环，无需引入新执行范式
- **有向无环图（DAG）结构**：多亲多子、无环、深度受限，子智能体可被多个主控智能体关联
- **最小侵入**：改动以追加为主，现有代码路径不受影响
- **自实现优先**：不引入 CrewAI/AutoGen/LangGraph 等外部编排框架（与 ADR-004 一致）

### 1.2 执行流程

```
用户消息
  │
  ▼
父智能体 (ReAct Loop, max_iterations=20)
  │
  ├─ tool: run_shell        → 沙盒执行
  ├─ tool: memory_read      → 记忆服务
  ├─ tool: delegate_task(child_A, task_1)
  │     │
  │     ├─ 验证 child_A 是父智能体的关联子级（via agent_relationships）
  │     ├─ 创建 Delegation 记录 (depth=1)
  │     ├─ 构建子智能体 AgentLoop
  │     │     ├─ system_prompt: 子级自有 || 继承父级
  │     │     ├─ model: 子级自有 || 父级 || 全局默认
  │     │     └─ tools: 子级 enabled_tools (无 delegate_task, depth=1)
  │     ├─ 子智能体执行 (max_iterations=10)
  │     │     ├─ tool: run_shell → 共享沙盒 (同一 session_id)
  │     │     └─ tool: write_file → 共享沙盒
  │     ├─ 返回子智能体最终输出
  │     └─ 更新 Delegation 记录 (status=completed)
  │
  ├─ tool: delegate_task(child_B, task_2)  ← 可与上面的并行
  │     └─ ... (同上)
  │
  ├─ 父智能体综合子智能体结果，继续推理
  └─ 输出最终回答
```

### 1.3 SSE 事件流

```
SSE: session          → 会话 ID
SSE: thinking         → 父智能体推理
SSE: tool_call        → 父智能体调用 delegate_task
  SSE: delegation_start        → 子智能体开始
  SSE: delegation_thinking     → 子智能体推理
  SSE: delegation_tool_call    → 子智能体调用工具
  SSE: delegation_tool_result  → 子智能体工具结果
  SSE: delegation_text_delta   → 子智能体文本流
  SSE: delegation_end          → 子智能体完成
SSE: tool_result      → 父智能体收到委派结果
SSE: text_delta       → 父智能体综合输出
SSE: done             → 完成
```

关键改动：工具执行阶段支持并行委派。

```python
class AgentLoop:
    def __init__(
        self,
        provider: LLMProvider,
        tool_executor: ToolExecutor,
        system_prompt: str = "",
        max_iterations: int = 20,
        trust_level: str = "ask_dangerous",
        delegation: DelegationContext | None = None,  # 新增
    ):
        # ... 现有属性 ...
        self.delegation = delegation

    async def run(self, user_input, user_id, session_id, conversation_history, tools):
        ctx = ToolContext(
            user_id=user_id,
            session_id=session_id,
            trust_level=self.trust_level,
            delegation=self.delegation,  # 注入委派上下文
        )
        # ... 消息构建不变 ...

        for step_num in range(1, self.max_iterations + 1):
            # ... LLM 流式调用不变 ...

            # 工具执行阶段 — 区分委派工具和普通工具
            delegation_calls = [tc for tc in step.tool_calls if tc.name == "delegate_task"]
            regular_calls = [tc for tc in step.tool_calls if tc.name != "delegate_task"]

            # 顺序执行普通工具
            for tc in regular_calls:
                result = await self.tool_executor.execute(
                    tool_name=tc.name,
                    arguments=tc.arguments,
                    tool_call_id=tc.id,
                    user_id=str(ctx.user_id),
                    session_id=str(ctx.session_id),
                )
                step.tool_results.append(result)
                # ... yield tool_result 事件不变 ...

            # 并行执行委派
            if delegation_calls:
                results = await self._execute_delegations_parallel(
                    delegation_calls, ctx
                )
                step.tool_results.extend(results)

            # ... 后续逻辑不变 ...

    async def _execute_delegations_parallel(
        self, tool_calls: list[ToolCall], ctx: ToolContext
    ) -> list[ToolResult]:
        """并行执行多个委派工具调用"""
        tasks = []
        for tc in tool_calls:
            tasks.append(
                self.tool_executor.execute(
                    tool_name=tc.name,
                    arguments=tc.arguments,
                    tool_call_id=tc.id,
                    user_id=str(ctx.user_id),
                    session_id=str(ctx.session_id),
                )
            )
        return await asyncio.gather(*tasks, return_exceptions=False)
```

```python
"""delegate_task 工具的处理函数"""

from __future__ import annotations

import asyncio
import json
import time
from datetime import datetime, timezone
from uuid import UUID

import structlog
from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession
from sqlalchemy.orm import selectinload

from aio_agent.core.agent import AgentLoop, AgentStep
from aio_agent.core.config import settings
from aio_agent.core.prompt import build_system_prompt
from aio_agent.db.connection import get_session_factory
from aio_agent.db.models import Agent, Delegation, LLMModel
from aio_agent.llm import LLMMessage, create_provider
from aio_agent.memory.service import MemoryService
from aio_agent.skills.service import SkillService
from aio_agent.tools.executor import ToolExecutor

logger = structlog.get_logger()


async def handle_delegate_task(
    arguments: dict,
    user_id: str,
    session_id: str,
    *,
    tool_executor: ToolExecutor,
    parent_agent_id: str | None = None,
    delegation_depth: int = 0,
    max_depth: int = 3,
    event_queue: asyncio.Queue | None = None,
) -> str:
    """处理 delegate_task 工具调用。

    由 ToolExecutor 的 direct_handler 机制调用。
    parent_agent_id, delegation_depth 等通过 ToolContext 注入。
    """
    child_agent_id = arguments.get("child_agent_id", "")
    task = arguments.get("task", "")
    context = arguments.get("context", "")

    if not child_agent_id or not task:
        return "错误：缺少必要参数 child_agent_id 或 task"

    # 深度检查
    if delegation_depth + 1 > max_depth:
        return f"错误：已达最大委派深度 {max_depth}，无法继续委派"

    t_start = time.monotonic()

    factory = get_session_factory()
    async with factory() as db:
        # 1. 加载并验证子智能体
        child = await _load_and_validate_child(
            db, UUID(child_agent_id), UUID(parent_agent_id) if parent_agent_id else None
        )
        if isinstance(child, str):  # 错误信息
            return child

        # 2. 创建委派记录
        delegation = Delegation(
            parent_session_id=UUID(session_id),
            parent_agent_id=UUID(parent_agent_id) if parent_agent_id else UUID(child_agent_id),
            child_agent_id=child.id,
            user_id=UUID(user_id),
            depth=delegation_depth + 1,
            task=task,
            context=context or None,
            status="running",
        )
        db.add(delegation)
        await db.commit()

        # 通知前端：委派开始
        if event_queue:
            await event_queue.put({
                "type": "delegation_start",
                "delegation_id": str(delegation.id),
                "child_agent_id": str(child.id),
                "child_agent_name": child.name,
                "task": task,
            })

        try:
            # 3. 构建子智能体的 AgentLoop
            child_loop, child_tools_schema = await _build_child_agent_loop(
                db, child, tool_executor, delegation_depth + 1, max_depth, event_queue, delegation.id,
            )

            # 4. 构建子智能体输入
            user_input = task
            if context:
                user_input = f"## 任务\n{task}\n\n## 背景上下文\n{context}"

            # 5. 执行子智能体
            final_output = ""
            async for event in child_loop.run(
                user_input=user_input,
                user_id=UUID(user_id),
                session_id=UUID(session_id),  # 复用父级 session（共享沙盒）
                conversation_history=[],       # 子智能体无历史
                tools=child_tools_schema,
            ):
                if isinstance(event, str):
                    # 代理子智能体事件到父级 SSE 流
                    if event_queue:
                        await event_queue.put({
                            "type": f"delegation_{_strip_prefix(event)}",
                            "delegation_id": str(delegation.id),
                            "raw": event,
                        })
                elif isinstance(event, AgentStep) and event.done:
                    final_output = event.final_output

            # 6. 更新委派记录
            duration = int((time.monotonic() - t_start) * 1000)
            delegation.status = "completed"
            delegation.result = final_output
            delegation.duration_ms = duration
            delegation.completed_at = datetime.now(timezone.utc)
            await db.commit()

            if event_queue:
                await event_queue.put({
                    "type": "delegation_end",
                    "delegation_id": str(delegation.id),
                    "status": "completed",
                    "result_preview": final_output[:500],
                    "duration_ms": duration,
                })

            return final_output

        except asyncio.TimeoutError:
            delegation.status = "timeout"
            delegation.error = f"委派超时（{settings.agent.delegation_timeout}秒）"
            delegation.duration_ms = int((time.monotonic() - t_start) * 1000)
            delegation.completed_at = datetime.now(timezone.utc)
            await db.commit()

            if event_queue:
                await event_queue.put({
                    "type": "delegation_end",
                    "delegation_id": str(delegation.id),
                    "status": "timeout",
                    "error": delegation.error,
                })
            return f"委派超时：子智能体 {child.name} 在 {settings.agent.delegation_timeout} 秒内未完成"

        except Exception as e:
            logger.error("委派执行失败", error=str(e), child_id=child_agent_id)
            delegation.status = "failed"
            delegation.error = str(e)
            delegation.duration_ms = int((time.monotonic() - t_start) * 1000)
            delegation.completed_at = datetime.now(timezone.utc)
            await db.commit()

            if event_queue:
                await event_queue.put({
                    "type": "delegation_end",
                    "delegation_id": str(delegation.id),
                    "status": "failed",
                    "error": str(e),
                })
            return f"委派失败：{e}"


async def _load_and_validate_child(
    db: AsyncSession, child_id: UUID, parent_id: UUID | None
) -> Agent | str:
    """加载子智能体并验证层级关系（via agent_relationships）"""
    result = await db.execute(
        select(Agent)
        .options(selectinload(Agent.skills), selectinload(Agent.model), selectinload(Agent.children))
        .where(Agent.id == child_id, Agent.is_active == True)
    )
    child = result.scalar_one_or_none()

    if not child:
        return f"错误：子智能体 {child_id} 不存在或已被禁用"

    if parent_id and not await _check_relationship(db, child.id, parent_id):
        return f"错误：智能体 {child_id} 不是当前智能体的关联子级"

    return child


async def _build_child_agent_loop(
    db: AsyncSession,
    child: Agent,
    parent_tool_executor: ToolExecutor,
    delegation_depth: int,
    max_depth: int,
    event_queue: asyncio.Queue | None,
    delegation_id: UUID,
) -> tuple[AgentLoop, list[dict]]:
    """构建子智能体的 AgentLoop"""

    # 1. 解析 system prompt（子级自有 || 继承父级 — 由调用方传入 parent_agent）
    #    此处简化：直接使用子智能体的 system_prompt
    agent_prompt = child.system_prompt

    # 2. 过滤子智能体的工具
    all_tools = parent_tool_executor.registry.list_tools()
    if child.enabled_tools:
        enabled_set = set(child.enabled_tools)
        filtered_tools = [t for t in all_tools if t.name in enabled_set]
    else:
        filtered_tools = all_tools

    # 移除 delegate_task（如果达到深度限制或子智能体没有子级）
    if delegation_depth >= max_depth or not child.children:
        filtered_tools = [t for t in filtered_tools if t.name != "delegate_task"]

    tools_schema = [
        {
            "type": "function",
            "function": {
                "name": t.name,
                "description": t.description,
                "parameters": t.parameters,
            },
        }
        for t in filtered_tools
    ]

    # 3. 构建 system prompt（注入记忆和技能）
    memory_data = await MemoryService.get_memories_for_prompt(
        db, UUID(str(child.created_by)), child.description or "", top_k=3
    )
    matched_skills = child.skills if child.skills else None

    system_prompt = build_system_prompt(
        tools=filtered_tools,
        persistent_memories=memory_data["l1_memories"],
        relevant_memories=memory_data["l2_memories"] + memory_data["l3_memories"],
        relevant_skills=matched_skills,
        agent_prompt=agent_prompt,
    )

    # 4. 构建 LLM Provider（子级模型 || 父级模型 || 全局默认）
    model_to_use = None
    if child.model_id:
        result = await db.execute(
            select(LLMModel)
            .options(selectinload(LLMModel.provider))
            .where(LLMModel.id == child.model_id, LLMModel.is_active == True)
        )
        model_to_use = result.scalar_one_or_none()

    if not model_to_use:
        result = await db.execute(
            select(LLMModel)
            .options(selectinload(LLMModel.provider))
            .where(LLMModel.is_default == True, LLMModel.is_active == True)
            .limit(1)
        )
        model_to_use = result.scalar_one_or_none()

    if not model_to_use or not model_to_use.provider:
        raise RuntimeError("没有可用的模型供子智能体使用")

    provider = create_provider(
        provider=model_to_use.provider.provider_type,
        model=model_to_use.model_name,
        base_url=model_to_use.provider.base_url,
        api_key=model_to_use.provider.api_key_encrypted,
        temperature=settings.llm.temperature,
    )

    loop = AgentLoop(
        provider=provider,
        tool_executor=parent_tool_executor,  # 复用父级的 tool_executor（共享沙盒）
        system_prompt=system_prompt,
        max_iterations=settings.agent.child_max_iterations,
        trust_level=settings.agent.trust_level,
    )

    return loop, tools_schema


def _strip_prefix(event: str) -> str:
    """从 AgentLoop 事件字符串中提取事件类型"""
    if event.startswith("text_delta:"):
        return "text_delta"
    elif event.startswith("reasoning:"):
        return "thinking"
    elif event.startswith("tool_call:"):
        return "tool_call"
    elif event.startswith("tool_result:"):
        return "tool_result"
    return "unknown"
```

```python
async def _would_create_cycle(
    db: AsyncSession, parent_id: UUID, child_id: UUID
) -> bool:
    """Check if adding parent->child would create a cycle.

    A cycle exists if child_id is an ancestor of parent_id
    (i.e., parent is already a descendant of child).
    BFS upward from parent_id through agent_relationships.
    """
    visited = set()
    queue = [parent_id]

    while queue:
        current = queue.pop(0)
        if current == child_id:
            return True
        if current in visited:
            continue
        visited.add(current)

        result = await db.execute(
            select(AgentRelationship.parent_id).where(
                AgentRelationship.child_id == current
            )
        )
        parents = result.scalars().all()
        queue.extend(parents)

    return False
```

```typescript
function handleDelegationEvent(event: SSEEvent) {
  switch (event.type) {
    case "delegation_start":
      // 创建新的委派卡片，状态为 running
      addDelegation({
        id: event.delegation_id,
        childAgentId: event.child_agent_id,
        childAgentName: event.child_agent_name,
        task: event.task,
        status: "running",
        thinking: "",
        toolCalls: [],
        result: "",
        error: "",
        durationMs: 0,
        expanded: true,  // 新委派默认展开
      });
      break;

    case "delegation_thinking":
      // 追加思考内容
      appendThinking(event.delegation_id, event.content);
      break;

    case "delegation_tool_call":
      // 添加工具调用
      addToolCall(event.delegation_id, {
        id: crypto.randomUUID(),
        name: event.name,
        arguments: event.arguments,
      });
      break;

    case "delegation_tool_result":
      // 更新工具结果
      updateToolResult(event.delegation_id, event.name, {
        status: event.status,
        preview: event.preview,
      });
      break;

    case "delegation_text_delta":
      // 追加结果文本
      appendResult(event.delegation_id, event.content);
      break;

    case "delegation_end":
      // 更新最终状态
      updateDelegation(event.delegation_id, {
        status: event.status,
        error: event.error || "",
        durationMs: event.duration_ms || 0,
        expanded: event.status !== "completed",  // 失败/超时保持展开
      });
      break;
  }
}
```

## 6. 安全设计

### 6.1 RLS 策略

`delegations` 表按 `user_id` 隔离，与现有表保持一致。

### 6.2 子智能体验证

Handler 中强制验证 `child.parent_agent_id == parent.id`，不信任客户端传入的 `child_agent_id`。

### 6.3 深度限制三层防护

| 层级 | 位置 | 机制 |
|------|------|------|
| L1 | `_filter_tools_by_agent()` | 达到深度时从 tools schema 中移除 `delegate_task`，LLM 根本看不到该工具 |
| L2 | `handle_delegate_task()` | Handler 内部检查 `depth + 1 > max_depth`，返回错误信息 |
| L3 | `delegations` 表 | `CHECK (depth > 0 AND depth <= 10)` 数据库硬约束 |

### 6.4 资源限制

- 子智能体 `max_iterations = 10`（父级为 20）
- 单次委派超时 300 秒
- 子智能体继承父级 `trust_level`

## 9. 架构决策记录

### ADR-010：委派建模为工具调用

**状态**：已决定

**决策**：将委派机制实现为 `delegate_task` 内置工具，通过 function calling 触发，而非引入 RPC、消息队列或独立的编排层。

**理由**：
- 现有 ReAct 循环已具备工具调用、结果注入、流式事件的完整基础设施
- LLM 天然理解 function calling，可以自主决定何时委派、委派给谁
- 无需引入新的执行范式或状态机
- 并行委派可以通过同一轮迭代的多个 tool_call 自然支持

**替代方案**：
- 独立编排层（类似 LangGraph）：增加系统复杂度，与 ADR-004 矛盾
- 消息队列异步委派：无法在同一轮对话中同步返回结果

### ADR-011：有向无环图（DAG）结构

**状态**：已决定

**决策**：智能体层级采用有向无环图（DAG）结构，支持多亲多子，通过 `agent_relationships` 关联表实现多对多关系，严格禁止环路。

**理由**：
- 子智能体可被多个主控智能体复用（如一个「编码专家」可被多个项目经理关联）
- 通过 BFS 遍历 ancestor 链检测环路，实现简单且可靠
- 前端层级展示支持多父级展示
- 委派深度按调用链实时计算，不依赖静态层级

**替代方案（已否决）**：
- 严格树形结构（单亲）：限制了子智能体的复用性，用户需要为每个主控智能体创建重复的子智能体

### ADR-012：委派记录独立于会话

**状态**：已决定

**决策**：子智能体的执行记录存储在 `delegations` 表中，而非创建独立的 `Session`。

**理由**：
- 委派更像函数调用而非独立对话，有明确的输入（task）和输出（result）
- 创建 Session 会污染用户的会话列表
- 子智能体无对话历史，任务描述即上下文
- 共享父级 `session_id` 可以复用沙盒环境
