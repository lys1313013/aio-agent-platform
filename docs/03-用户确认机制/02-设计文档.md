# 智能体平台 - 用户确认系统设计

## Context

当前 Agent 平台的对话流程是"用户发消息 -> Agent 自主推理+执行 -> 返回结果"的单向模式。但在很多场景下，Agent 需要**中途暂停**，向用户展示选项或请求决策，等用户选择后再继续执行。

### 为什么需要用户确认？

| 场景 | 示例 |
|------|------|
| **方案选择** | Agent 生成了 3 种实现方案，让用户选一个 |
| **操作确认** | 要执行 `rm -rf ./dist` 等危险命令，需用户批准 |
| **信息补充** | 需求不明确时，问用户"你想要 JSON 还是 YAML 格式？" |
| **计划审批** | Agent 生成完整执行计划，用户审批后才开始执行 |
| **批量操作** | 需要修改 15 个文件，列出清单让用户确认范围 |
| **技能保存** | Agent 从对话中提取了技能，问用户是否保存 |

### 参考设计：Claude Code 的确认模式

Claude Code 有 3 种核心确认机制：

1. **Question Tool**：Agent 主动提问，用户自由文本回答（阻塞式）
2. **Plan Mode**：Agent 生成计划 -> 用户 Approve/Reject/Modify（支持多轮修改）
3. **Permission Prompt**：工具执行前弹出确认，用户可选 Allow once / Allow always / Deny

我们要做的是把这些模式**适配到 Web 聊天界面**中，利用已有的 SSE 流式架构。

## 核心设计：`AskUserQuestion` 工具 + SSE 暂停-恢复协议

### 设计哲学（来自 Claude Code）

- **人机协作**：用户始终在控制回路中（human-in-the-loop）
- **渐进式信息披露**：只在真正需要人类判断时才中断
- **最低中断原则**：低风险操作自动执行，高风险/有歧义时才询问
- **可配置自主度**：用户可通过 trust_level 控制确认频率

### 架构总览

```
Agent Loop (ReAct)
    │
    ├── 正常推理 → 调用工具 → 返回结果 → 继续推理
    │
    └── 需要用户决策 → 调用 AskUserQuestion 工具
                          │
                          ├── SSE 推送 confirmation_required 事件
                          │     （包含：问题、选项、类型、元数据）
                          │
                          ├── Agent Loop 挂起 (asyncio.Event.wait)
                          │
                          ├── 前端渲染确认卡片
                          │     （单选/多选/自由输入/方案对比）
                          │
                          ├── 用户选择 → REST API 提交
                          │
                          ├── asyncio.Event.set() → Agent Loop 恢复
                          │
                          └── 用户选择作为 ToolResult 返回给 Agent
```

**关键决策**：SSE 连接保持不断开，确认响应走独立的 REST API，通过内存中的 `asyncio.Event` 字典协调。这和 Claude Code 的阻塞式 Question Tool 思路一致。

## 三、后端实现

### 3.1 确认管理器（内存状态管理）

```python
# src/aio_agent/core/confirmation.py

import asyncio
import uuid
from datetime import datetime, timezone
from typing import Optional
from dataclasses import dataclass, field

@dataclass
class PendingConfirmation:
    """一个等待中的用户确认请求"""
    id: str                            # UUID
    session_id: str
    user_id: str
    question: str
    mode: str                          # single_select / multi_select / free_input / approve
    options: list[dict]
    context: dict
    event: asyncio.Event = field(default_factory=asyncio.Event)
    response: Optional[dict] = None    # 用户响应后填充
    created_at: datetime = field(default_factory=lambda: datetime.now(timezone.utc))
    timeout_seconds: int = 300

class ConfirmationManager:
    """管理所有等待中的确认请求"""

    def __init__(self):
        self._pending: dict[str, PendingConfirmation] = {}

    async def request_confirmation(
        self,
        session_id: str,
        user_id: str,
        question: str,
        mode: str,
        options: list[dict] | None = None,
        context: dict | None = None,
    ) -> PendingConfirmation:
        """创建确认请求并等待用户响应（阻塞）"""
        ctx = context or {}
        timeout = ctx.get("timeout_seconds", 300)

        confirmation = PendingConfirmation(
            id=str(uuid.uuid4()),
            session_id=session_id,
            user_id=user_id,
            question=question,
            mode=mode,
            options=options or [],
            context=ctx,
            timeout_seconds=timeout,
        )
        self._pending[confirmation.id] = confirmation

        try:
            # 阻塞等待，直到用户响应或超时
            await asyncio.wait_for(confirmation.event.wait(), timeout=timeout)
            return confirmation
        except asyncio.TimeoutError:
            confirmation.response = {"status": "timeout"}
            return confirmation
        finally:
            # 清理
            self._pending.pop(confirmation.id, None)

    def resolve_confirmation(self, confirmation_id: str, response: dict) -> bool:
        """用户响应确认请求"""
        confirmation = self._pending.get(confirmation_id)
        if not confirmation:
            return False
        confirmation.response = response
        confirmation.event.set()
        return True

    def get_pending(self, session_id: str) -> list[PendingConfirmation]:
        """获取会话的所有待确认请求"""
        return [c for c in self._pending.values() if c.session_id == session_id]


# 全局单例
confirmation_manager = ConfirmationManager()
```

### 3.2 `AskUserQuestion` 工具执行器

```python
# tools/handlers/AskUserQuestion.py

async def execute_AskUserQuestion(
    question: str,
    mode: str = "single_select",
    options: list[dict] | None = None,
    context: dict | None = None,
    **kwargs
) -> dict:
    """AskUserQuestion 工具的执行函数"""
    ctx = kwargs.get("context")  # ToolContext，包含 user_id, session_id 等

    # 1. 创建确认请求（阻塞等待用户响应）
    confirmation = await confirmation_manager.request_confirmation(
        session_id=ctx.session_id,
        user_id=ctx.user_id,
        question=question,
        mode=mode,
        options=options,
        context={
            **(context or {}),
            "agent_id": ctx.agent_id,
            "agent_name": ctx.agent_name,
        },
    )

    # 2. 构造返回给 Agent 的结果
    response = confirmation.response
    if not response or response.get("status") == "timeout":
        return {
            "status": "timeout",
            "message": "用户未在限定时间内响应，请自行决定或稍后重试。"
        }

    if response.get("status") == "rejected":
        return {
            "status": "rejected",
            "message": "用户拒绝了此操作。请选择其他方案。"
        }

    if mode == "free_input":
        return {
            "status": "answered",
            "user_input": response.get("user_input", ""),
            "message": f"用户回答：{response.get('user_input', '')}"
        }

    # single_select / multi_select / approve
    selected = response.get("selected_options", [])
    selected_labels = [
        opt["label"] for opt in (options or [])
        if opt["id"] in selected
    ]
    return {
        "status": "answered",
        "selected": selected,
        "selected_labels": selected_labels,
        "message": f"用户选择了：{', '.join(selected_labels)}"
    }
```

### 3.3 Agent Loop 集成（SSE 事件发射）

Agent Loop 中需要拦截 `AskUserQuestion` 工具调用，在等待用户响应期间通过 SSE 发送确认请求事件：

```python
# core/agent.py 中的关键改造点

async def _handle_tool_call(self, tool_call, ctx, sse_queue):
    tool_name = tool_call["function"]["name"]
    args = json.loads(tool_call["function"]["arguments"])

    if tool_name == "AskUserQuestion":
        # 1. 立即通过 SSE 推送确认请求
        confirmation_data = {
            "question": args["question"],
            "mode": args.get("mode", "single_select"),
            "options": args.get("options", []),
            "context": {
                **(args.get("context") or {}),
                "agent_id": ctx.agent_id,
                "agent_name": ctx.agent_name,
            },
        }

        # 先创建 PendingConfirmation（获取 ID）
        pending = await confirmation_manager.request_confirmation_async(
            session_id=ctx.session_id,
            user_id=ctx.user_id,
            **confirmation_data,
        )
        # 注意：这里需要拆分创建和等待两步
        # 先创建拿到 confirmation_id，推送 SSE，然后等待

        await sse_queue.put({
            "type": "confirmation_required",
            "data": {
                "confirmation_id": pending.id,
                **confirmation_data,
            }
        })

        # 2. 阻塞等待用户响应
        confirmation = await confirmation_manager.wait_for_response(pending.id)

        # 3. 推送已解决事件
        await sse_queue.put({
            "type": "confirmation_resolved",
            "data": {
                "confirmation_id": pending.id,
                "status": confirmation.response.get("status", "unknown"),
                "selected_options": confirmation.response.get("selected_options"),
                "user_input": confirmation.response.get("user_input"),
                "resolved_at": datetime.now(timezone.utc).isoformat(),

        })

        # 4. 返回工具结果给 Agent

# interface/routes/confirmations.py

from fastapi import APIRouter, Depends
from pydantic import BaseModel

router = APIRouter(prefix="/api/confirmations", tags=["confirmations"])

class ConfirmResponseRequest(BaseModel):
    """用户响应确认请求"""
    status: str  # "approved" | "rejected"
    selected_options: list[str] | None = None   # 选中的选项 ID
    user_input: str | None = None               # 自由输入文本

class ConfirmResponseResponse(BaseModel):
    success: bool
    message: str = ""

@router.post("/{confirmation_id}/respond", response_model=ConfirmResponseResponse)
async def respond_to_confirmation(
    confirmation_id: str,
    body: ConfirmResponseRequest,
    user: User = Depends(get_current_user),
):
    """用户响应确认请求"""
    resolved = confirmation_manager.resolve_confirmation(
        confirmation_id,
        response={
            "status": body.status,
            "selected_options": body.selected_options or [],
            "user_input": body.user_input,
        },
    )
    if not resolved:
        return ConfirmResponseResponse(
            success=False,
            message="确认请求不存在或已过期"
        )
    return ConfirmResponseResponse(success=True)

  const [selected, setSelected] = useState<string[]>([]);

  const toggle = (id: string) => {
    setSelected(prev =>
      prev.includes(id)
        ? prev.filter(s => s !== id)
        : [...prev, id]
    );
  };

  return (
    <div className="space-y-2">
      <div className="text-sm text-gray-500 mb-2">
        已选择 {selected.length} / {options?.length} 项
      </div>

      {/* 选项列表（带复选框） */}
      {options?.map((option) => (
        <div
          key={option.id}
          onClick={() => toggle(option.id)}
          className={`border rounded-lg p-3 cursor-pointer
            ${selected.includes(option.id) ? 'border-blue-500 bg-blue-50' : 'border-gray-200'}`}
        >
          <Checkbox checked={selected.includes(option.id)}>
            <span className="font-medium">{option.label}</span>
            {option.description && (
              <p className="text-sm text-gray-500">{option.description}</p>
            )}
          </Checkbox>
        </div>
      ))}

      {/* 提交 */}
      <div className="flex justify-end gap-2 mt-3">
        <Button onClick={() => onSubmit({ status: "rejected" })}>跳过</Button>
        <Button
          type="primary"
          disabled={selected.length === 0}
          onClick={() => onSubmit({
            status: "approved",
            selected_options: selected,
          })}
        >
          确认选择 ({selected.length})
        </Button>
      </div>
    </div>
  );
};
```

## 七、超时处理策略

| 场景 | 超时时间 | 超时行为 |
|------|---------|---------|
| 方案选择 (plan) | 5 分钟 | Agent 收到 timeout，自行选择最优方案继续 |
| 危险操作确认 (tool_confirm) | 3 分钟 | Agent 收到 timeout，跳过此操作，尝试安全替代方案 |
| 需求澄清 (clarify) | 10 分钟 | Agent 收到 timeout，基于已有信息继续 |
| 技能保存 (skill_save) | 5 分钟 | 默认不保存（超时=拒绝） |
| 批量操作 (batch_action) | 5 分钟 | Agent 执行全部（超时=全选） |

**前端倒计时**：`ConfirmationTimer` 组件展示剩余时间，最后 30 秒变为红色闪烁提醒。

## 八、数据持久化（可选，Phase 2）

初期确认请求仅存在内存中（asyncio.Event），无需数据库表。后续如需审计/历史查看，可增加：

```sql
-- Alembic migration

CREATE TABLE confirmation_logs (
    id            UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id       UUID NOT NULL,
    session_id    UUID NOT NULL,
    agent_id      UUID,
    question      TEXT NOT NULL,
    mode          VARCHAR(32) NOT NULL,
    options       JSONB DEFAULT '[]',
    context       JSONB DEFAULT '{}',
    status        VARCHAR(32) NOT NULL,       -- approved / rejected / modified / timeout
    response      JSONB DEFAULT '{}',         -- 用户的响应内容
    created_at    TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    resolved_at   TIMESTAMPTZ
);

CREATE INDEX idx_cfmlog_user ON confirmation_logs(user_id);
CREATE INDEX idx_cfmlog_session ON confirmation_logs(session_id);

ALTER TABLE confirmation_logs ENABLE ROW LEVEL SECURITY;
CREATE POLICY confirmation_logs_rls ON confirmation_logs
    USING (user_id = current_setting('app.current_user_id')::uuid);
```
