# 大模型可观测性前端展示设计

> 日期：2026-08-06
> 对应《01-需求文档.md》§4.1，基于 **Ant Design 6 + @ant-design/plots + React 18** 实现。设计依据 ui-ux-pro-max 设计系统（风格：Data-Dense Dashboard）。

## 1. 设计目标与原则

观测页是**管理员运营工具**，核心是"数据密集、状态一目了然、可快速下钻定位问题"：

1. **一眼看清现状**：指标卡 + 状态色，不用进页面点图表。
2. **逐层下钻**：监控板（异常信号）→ Trace 明细（异常实例）→ 单 Trace 展开（根因）→ 代码/日志。路径始终可回退。
3. **数据可扫描**：表格、等宽数字、紧凑间距；信息密度优先，装饰让位于数据。
4. **只改必要之处**：复用 AntD 6 组件与 `/usage` 已有模式，新增 4 个业务组件，避免过度自研。

## 2. 设计系统

### 2.1 风格

- **Data-Dense Dashboard**：多图表/多表格/KPI 卡、最小留白、网格布局、空间高效。
- 浅色 + 深色双主题（跟随平台全局主题）。

### 2.2 配色（语义 Token，映射 AntD 6 Design Token）

| Token | 值 | 用途 |
|---|---|---|
| `colorPrimary` | `#1E40AF` | 主色：选中态、主按钮、激活导航 |
| `colorInfo` | `#3B82F6` | 信息：次级强调、图表默认系列 |
| `colorWarning` | `#D97706` | 警告：延迟偏高、接近阈值 |
| `colorError` | `#DC2626` | 错误：失败率、错误状态 |
| `colorSuccess` | `#16A34A` | 成功：正常状态、completed |
| `colorBgLayout` | `#F8FAFC` | 页面背景 |
| `colorBorder` | `#DBEAFE` | 边框、分隔线 |
| `colorText` | `#1E3A8A` | 主文本 |

> 状态色只用于**语义**（成功/失败/警告），不用于装饰。前端通过 `ConfigProvider theme.token` 注入，组件内不出现裸 hex。

### 2.3 图表系列色板（按优先级取用）

```
#2563EB  #4F46E5  #0891B2  #7C3AED  #D97706  #EA580C
```

多系列趋势**同时用线型区分**（实线/虚线/点线），不依赖颜色（无障碍要求）。

### 2.4 字体

- 正文：`Fira Sans`（跟随平台，缺失回退系统字体）。
- **数字/代码**：`Fira Code`——trace_id、时间戳、指标卡数值、表格数字列（等宽防止列宽跳动）。
- 引入方式：`@import` Google Fonts；数字类组件统一用 `font-family: 'Fira Code', monospace`。

### 2.5 效果与动效

- 悬停 tooltip 显示精确值；表格行 hover 高亮；图表 hover 十字线。
- 动效 150–300ms；尊重 `prefers-reduced-motion`。
- 不做花哨入场动画；数据刷新用轻量 crossfade，避免整页闪烁。

## 3. 信息架构

```
侧边栏（新增，位于"用量统计"上方）
└─ 可观测性  /observability   [LineChartOutlined]
   └─ Tab 页：
       Overview（实时监控板）    默认页
       Traces（Trace 明细）
       Stats（聚合报表）
       Tools（工具排行）
       Quality（对话质量）
```

- 路由 `/observability`，子模块用 `Tabs`（URL query 同步 tab，如 `?tab=traces`，可深链）。
- 权限：管理员可见；普通用户侧边栏不渲染该菜单。

## 4. 全局框架

每个子模块顶部有统一筛选栏，筛选状态写入 URL query（可分享/回退保留）：

```
[时间范围 Select: 近1小时/近24小时/近7天/近30天/自定义]
[模型 Select 多选] [智能体 Select 多选] [状态 Select]
[刷新 Select: 关闭/30s/1m]（仅 Overview 显示）  [导出 CSV]（列表模块显示）
```

- 时间范围默认：Overview=近24小时，其余=近7天。
- 自定义时间用 `DatePicker.RangePicker`（禁用未来）。
- 筛选变化 → 更新 URL + 触发查询；回退浏览器恢复筛选（AntD 与 router 协同）。

## 5. 页面详细设计

### 5.1 Overview（实时监控板）

**目标**：30 秒内判断"平台现在是否健康、异常在哪"。

```
┌────────────────────────────────────────────────────────────────────────┐
│ 筛选栏（时间/模型/智能体 + 自动刷新 + 最后刷新时间）                          │
├────────────────────────────────────────────────────────────────────────┤
│  ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐│
│  │调用数 12.4k│ │LLM失败率 │ │工具错误率│ │平均TTFT │ │延迟P95  │ │今日token ││
│  │  ↑12%   │ │  0.8%   │ │  1.2%   │ │ 320ms   │ │ 8.5s    │ │ 1.2M    ││
│  │ [spark] │ │ [spark] │ │ [spark] │ │ [spark] │ │ [spark] │ │ [spark] ││
│  └─────────┘ └─────────┘ └─────────┘ └─────────┘ └─────────┘ └─────────┘│
├────────────────────────────────────────────────────────────────────────┤
│  ┌ LLM调用量 ────────────────┐ ┌ LLM失败率 ──────────────────┐ ┌ 工具调用量 ────────────────┐ │
│  │ Line(分钟粒度)              │ │ Line + 异常高亮区            │ │ Line(分钟粒度)              │ │
│  └────────────────────────────┘ └────────────────────────────┘ └────────────────────────────┘ │
├───────────────────────────────────────────────────────────────────────────────────────────────┤
│  ┌ 工具失败率 ────────────────┐ ┌ 延迟 P95 ──────────────────┐ ┌ 上下文利用率 P95 ────────────┐ │
│  │ Line(阈值线20% + 高亮)      │ │ Line(阈值线30s虚线)         │ │ Line(阈值线90%虚线)          │ │
│  └────────────────────────────┘ └────────────────────────────┘ └────────────────────────────┘ │
└───────────────────────────────────────────────────────────────────────────────────────────────┘
```

**组件与交互**
- **StatCard（自建）**：标题 + 大数字（Fira Code）+ 环比（↑/↓ 箭头 + 百分比，`#16A34A`/`#DC2626`）+ 迷你面积图（sparkline）。数值超阈值时卡底色轻提示（失败率红、延迟琥珀）。
- 4→6 张趋势图用 `ChartCard`（自建容器：标题 + 图例 + 悬停 value），LLM 与工具维度**各自独立成图**，左右不混排。
- **异常高亮**：LLM/工具失败率两张图中，超阈值时段用红色标记点 + 文字标注；点击标记跳转 Traces 页（带该时段筛选）。
- **自动刷新**：默认 30s，可暂停；刷新时图表 crossfade，不整页 loading；显示"最后刷新 HH:mm:ss"。
- 空数据：展示 `Empty`（"该时段暂无数据，尝试扩大时间范围"），不显示空坐标轴。

### 5.2 Traces（Trace 明细）

**目标**：按条件找异常 Trace，进入单条展开。

```
┌────────────────────────────────────────────────────────────────────────┐
│ 筛选栏 + [导出 CSV]  [列配置 Popover]                                       │
├────────────────────────────────────────────────────────────────────────┤
│ Table (virtual, 每页50):                                                  │
│  trace_id(短码)│ 时间     │ 会话(标题截断)│ 智能体│ 模型  │ 轮数│ 工具│ 总token│ 耗时│ 状态 │
│  a1b2c3d4   │ 10:32:05 │ 帮我分析报表… │ 数据助手│ claude│ 4   │ 3  │ 28.5k  │ 42s│ ●失败 │
│  ...每行 hover 高亮，行点击 → 详情抽屉                                         │
├────────────────────────────────────────────────────────────────────────┤
│ 分页 + 总数（"共 1,234 条，筛选 89 条"）                                       │
└────────────────────────────────────────────────────────────────────────┘
```

**组件与交互**
- **StatusTag（自建）**：状态 = 图标 + 文字 + 颜色（completed=绿/中断=灰/interrupted/error=红/timeout=琥珀），**不只靠颜色**。
- 列：`trace_id` 用短码（前 8 位）+ hover tooltip 显示全 ID + 一键复制按钮。
- 会话列超长省略号 + tooltip 全文。
- 数字列右对齐、Fira Code 等宽。
- 排序：时间（默认降序）、耗时、token 可排序；`aria-sort` 标注。
- 导出 CSV 与当前筛选一致。

### 5.3 Trace 详情下钻（Drawer）

**目标**：还原一次 Agent 执行全链路，定位慢/错的环节。

```
┌ Drawer (80% 宽) ──────────────────────────────────────────────┐
│ 头：trace_id(全) [复制] · 会话 · 智能体 · 模型 · 状态 · 开始/结束时间   │
│     汇总条: 轮数 4 · 工具 3 · 总token 28.5k · 总耗时 42s           │
├──────────────────────────────────────────────────────────────┤
│ 执行时间轴（TraceTimeline，自建）                                │
│  ┌─LLM#1──┐ ┌tool:search────┐ ┌─LLM#2──┐ ┌tool:delegate──┐      │
│  │ 6.2k t │ │ 1.8s  ✓ 3.4k   │ │ 8.1k t │ │ 12s  ✓ 4.2k    │      │
│  │ TTFT 240ms│ │ 输出 1.2KB   │ │ TTFT 180ms│ │ 嵌套2层      │      │
│  └────────┘ └───────────────┘ └────────┘ └───────────────┘      │
│  [压缩事件: 28.5k → 9.4k，节省 19.1k]                            │
├──────────────────────────────────────────────────────────────┤
│ 选中节点详情面板（右侧）: 该次 LLM/工具的完整字段 + 错误信息/建议   │
└──────────────────────────────────────────────────────────────┘
```

**组件与交互**
- **TraceTimeline（自建）**：水平时间轴/泳道，LLM 节点与工具节点按顺序排布，长度按 duration_ms 比例映射；状态色描边；点击节点右侧面板显示详情。
- 节点详情面板字段：LLM（token 明细/缓存/TTFT/耗时/stop_reason/error_type/参数）或工具（exec_type/耗时/输出大小/截断/错误）。
- 压缩事件作为独立节点插入时间轴，标注前后 token 与节省量。
- 错误节点展开后给出可读错误描述（映射表）——不止显示枚举。
- 键盘：Drawer 内方向键在节点间移动，Esc 关闭。

### 5.4 Stats（聚合报表）

**目标**：按维度看 token/耗时/错误率分布，定位"大头在哪"。

```
┌ 筛选栏 ────────────────────────────────────────────────────┐
├  Segmented: [模型] [智能体] [用户] [租户]                      │
│  口径 Switch: [token] [耗时] [错误率]                         │
├───────────────────────────────────────────────────────────┤
│ ┌ 横向 Bar（Top 20，默认降序）────┐  ┌ 明细 Table ─────────┐  │
│ │ 模型A ████████████ 1.2M       │  │ 名称│ token│ 调用│ 耗时 │  │
│ │ 模型B ██████████ 980k         │  │ ...                │  │
│ │ ...                           │  │                    │  │
│ └───────────────────────────────┘  └────────────────────┘  │
│ 图例 + 总值标注；点击条 → 该维度单独视图（二次筛选）            │
└───────────────────────────────────────────────────────────┘
```

**规范**
- 分类 ≥5 用横向 Bar（skill：避免 >5 类的饼图）；≤5 类才用 Donut。
- Bar 默认降序，value 标签常显。
- 表格与图联动：点击图表条下钻该维度（叠加筛选）。

### 5.5 Tools（工具排行）

**目标**：定位"哪个工具最慢/最容易错/最烧 token"。

```
┌ 筛选栏 ────────────────────────────────────────────────────┐
├  Segmented(指标): [平均耗时] [错误率] [调用次数] [注入token]    │
├  List (横向 Bar + 排名):                                    │
│  #1 web_search     avg 4.2s ████████████  error 2.1%  调用 1.2k │
│  #2 file_read      avg 1.8s ███████       error 0.4%  调用 980  │
│  ...（可滚动，Top 50）                                        │
├  表格视图切换: 名称│调用数│成功│失败│错误率│avg耗时│P95│注入token│   │
└───────────────────────────────────────────────────────────┘
```

**规范**
- 指标切换用 `Segmented`；每行同显 4 个口径（主指标条形，其余数值）。
- 错误率 > 20% 的工具有红色标记 + 行警示。
- 支持列表/表格双视图切换。
- **单工具趋势下钻**：点击某工具行，底部展开/或弹出该工具的时间序列（`Line`，调用量 + 失败率，分钟/小时/天切换，含阈值线）——回答"这个工具何时开始慢/开始出错"。

### 5.6 Quality（对话质量）

**目标**：看整体对话体验与上下文压缩收益趋势。

```
┌ 筛选栏 ────────────────────────────────────────────────────┐
├  指标卡: 对话平均耗时 · 对话平均token · 每轮LLM调用 · 多轮占比    │
├  趋势（近7天/30天，Line）:                                    │
│  对话平均耗时 ──   对话平均token ──（双轴或分列）                │
│  压缩触发率 ──（含阈值线 30%）  压缩节省量(累计) ──              │
│  首响延迟 P50/P95 ──                                         │
└───────────────────────────────────────────────────────────┘
```

**规范**
- 趋势均用 Line；多指标用线型+图例区分，避免 >6 系列（拆图）。
- 压缩触发率带阈值参考线；压缩节省量用面积图强调累积收益。
- 双指标轴场景：优先分列两张图而非双 Y 轴（可读性）。

## 6. 图表规范（@ant-design/plots）

| 场景 | 图表 | 配置要点 |
|---|---|---|
| 时间序列趋势 | `Line` | 线型区分系列；阈值线用 `markLine` 虚线；网格线低对比 |
| 分布/占比（≤5 类） | `Pie` | 图例可见、悬停 tooltip |
| 分布/排行（≥5 类） | `Bar`（横向） | 降序、value 常显 |
| KPI 迷你趋势 | `Area`（mini） | 高度 32px，弱化坐标 |
| 异常标记 | `Line` + point | 异常点用形状（圆点）+ 颜色 + 文字标注 |

通用：图例靠近图（不落到折叠线下）；tooltip 含精确值与单位；时间轴标注粒度（分钟/小时/天）与可切换；数据 ≥1000 点由后端聚合抽样；图表入口动画尊重 `prefers-reduced-motion`。

## 7. 状态规范

| 状态 | 表现 |
|---|---|
| 加载 | 页面骨架屏（Skeleton）+ 图表 loading 态；>300ms 才出现，避免闪烁 |
| 空数据 | `Empty` + 引导文案 + 恢复默认筛选按钮；不显示空白坐标轴 |
| 错误 | 错误提示 + 重试按钮；图表失败显示错误态而非空白框 |
| 刷新中 | 监控板 crossfade + "最后刷新时间"；不做整页 spinner |
| 阈值超限 | 相关卡/行/点用状态色 + 图标 + 文字三重提示 |

## 8. 通用交互与无障碍

- **深链与状态保留**：筛选/Tab 全部入 URL query；回退恢复滚动与筛选。
- **对比度**：正文 ≥4.5:1；状态色卡满足 AA。
- **键盘**：表格排序 `aria-sort`；时间轴节点可方向键聚焦；Drawer Esc 关闭。
- **动效**：150–300ms；`prefers-reduced-motion` 降级为无动画切换。
- **触控**：可点击行/条目标 ≥44px 命中区。
- **无障碍图表**：每张图配文字摘要（如 `aria-label="近24小时调用量趋势，峰值出现在 14:00"`）+ 数据表格可达（Stats/Tools 已天然有表格）。

## 10. 实现备注

- `ConfigProvider` 覆盖 `theme.token`（§2.2 色板 + Fira Code 数字）。
- 路由 `/observability` 懒加载（`React.lazy`），子模块 Tab 用 query 驱动。
- 接口对齐《02-技术方案.md》§7：Overview→`/overview`，Traces→`/traces`，下钻→`/traces/{id}`，Stats→`/stats`，Tools→`/tool-ranking`，Quality→`/quality`。
- 指标卡数字与时间用 Fira Code 等宽，避免刷新跳动。
- 分页/排序/筛选均走服务端（数据量大，前端不做全量拉取）。
