# Web 对话后台执行与中断恢复

## 用户行为

- 普通聊天、智能体聊天、门户、宠物对话都使用后台任务。刷新、切换会话、离开页面、关闭宠物面板仅断开订阅。
- 再次进入会话自动查询任务，加载历史并从头重建该轮实时进度。通过任务 ID、事件序号和消息 ID 去重，不把回放重复追加到旧状态。
- 普通聊天地址增加 `/chat/:sessionId`，刷新和前进后退可定位对应会话。
- “停止”显式请求后端取消父任务及其委派子任务，保存已有进度。队列“立即发送”等待停止完成后才发送下一条，不再靠固定延迟猜测。
- 同一会话只能有一个运行中的 Web 任务。运行中会话必须先停止才能删除。
- 正常停机保存任务为中断；进程被强制终止时，心跳超出 30 秒后，在状态查询或订阅时标记中断。不会因另一副本启动而把健康任务误标为中断。
- 停止、失败、中断后的任务满足安全条件时显示“继续任务”。有结果未知或失败的工具调用时禁止一键续跑，提示先核对外部实际结果。

## 执行与持久化

`POST /api/chat/stream` 保留现有 SSE 形状，新增后台生产者。响应流只是 PostgreSQL 事件订阅者，不拥有 `AgentLoop` 的生命周期。

- `chat_runs`：任务归属、状态、执行进程、心跳、请求、快照、助手消息 ID、续跑来源。
- `chat_run_events`：按 `(run_id, sequence)` 排序的持久事件。
- 会话行锁和运行任务部分唯一索引共同防止并发重复启动。所有查询显式限制用户，新增表同时启用 RLS。
- 工具调用事件在推进 AgentLoop 到执行阶段前持久化，工具结果也在推进下一步前提交。文本增量按时间/条数批量提交；强制终止可能丢失最后尚未提交的文本批次。
- 运行任务每秒更新心跳并检查停止请求；数据库不可用或任务所有权失效时取消本地执行。旧执行者不能把已中断任务重新写为完成。
- 完成事件在任务终态提交后才发给订阅者，避免前端队列抢跑。完成事件已持久化后进程崩溃，会恢复为已完成。
- 删除会话同时删除任务和事件记录；当前没有额外的定时日志清理策略。

## 安全续跑的含义

续跑建立关联到原任务的新一轮，并使用持久化对话与工具结果继续。它不是 Python 调用栈恢复，也不会重新提交原始用户问题。

- 同名、同参数的已完成工具调用直接复用旧结果，包含连续多次续跑的结果；不再次执行对应外部操作。
- 存在没有持久成功结果的调用时，禁止一键续跑。即使错误响应已到达，外部系统也可能已产生副作用，因此不把失败自动视作安全重试。
- 工具结果未知时，历史消息明确标记未知，并补充符合模型协议的工具响应，避免缺少 `tool_call_id` 对应结果导致后续请求失败。
- 历史浏览器动作不会因事件回放而重新点击、输入或提交。离开页面后的浏览器工具仍受现有前台/超时约束；后端计算和工具调用可以继续。
- 保护针对已有调用记录和精确匹配的参数。修改参数的业务操作仍由正常工具权限、确认机制及用户核对约束，不能承诺外部系统的通用 exactly-once。
- 当前确认和浏览器动作管理器仍在进程内；多副本部署的确认/浏览器回包需要保持原有会话粘性。任务状态、事件重连和停止请求本身可跨副本访问。

## 新增接口

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/chat/sessions/{session_id}/run` | 最新任务状态和续跑条件 |
| GET | `/api/chat/runs/{run_id}/events?after=0` | 回放与实时订阅，`after` 为最后消费的序号 |
| POST | `/api/chat/runs/{run_id}/stop` | 明确停止，等待保存终态 |
| POST | `/api/chat/runs/{run_id}/resume` | 安全条件检查后建立续跑任务，并返回 SSE |

新增事件 `run`、`run_status` 携带任务 ID、状态、助手消息 ID、可续跑标志和结果不确定的工具列表。事件保留原有业务字段，并增加 `run_id`、`sequence`、`replay`。

## 迁移与验证

迁移版本：`e1f2a3b4c5d6`，前置版本 `d0e1f2a3b4c5`。发布时先执行 `cd backend && uv run alembic upgrade head`，再启动包含新代码的服务。

自动回归：

```bash
cd backend
uv run pytest tests/test_chat_runs.py tests/test_chat_turn_history.py tests/test_agent_time_context.py -q
uv run ruff check src/
uv run mypy src/

cd ../frontend
npm run test
npm run build
```

`test_chat_runs.py` 使用独立临时数据库，覆盖实际聊天路由断线后后台完成、多个订阅、持久事件游标、任务停止和子任务取消、过期心跳、消息抢救、归属隔离、重复启动、续跑保护及已完成工具结果复用。前端测试覆盖自动连接、切换会话只断开订阅、过期回调隔离、去重、显式停止及不安全续跑拦截。

本轮未连接业务数据库或真实模型；Docker 未运行，尚未做真实 PostgreSQL 锁/RLS 及线上重启验收。当前 Node 运行前端全量测试时需要 `NODE_OPTIONS=--no-experimental-webstorage`，避免 Node 自带实验性 localStorage 覆盖测试 DOM 的实现。
