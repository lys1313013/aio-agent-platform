## 2. 单轮对话执行链路

```mermaid
sequenceDiagram
    autonumber
    actor U as 用户
    participant F as React 前端
    participant A as FastAPI Chat API
    participant C as Chat Service
    participant L as AgentLoop
    participant M as LLM Provider
    participant T as ToolExecutor
    participant X as 工具 / Sandbox / MCP
    participant D as PostgreSQL

    U->>F: 发送消息
    F->>A: POST 对话请求并建立 SSE
    A->>C: 校验用户、会话、Agent、Workspace
    C->>D: 保存用户消息并加载上下文
    C->>L: 构建 Prompt 与 ToolContext

    loop ReAct，直到输出完成或达到 max_iterations
        L->>M: 流式请求 messages + tool schemas
        M-->>L: reasoning / text_delta / tool_calls
        L-->>A: 流式事件
        A-->>F: SSE thinking / text_delta / tool_call

        alt 模型请求普通工具
            L->>T: 并发执行工具调用
            T->>T: 白名单、权限和安全校验
            T->>X: 路由到内置、Direct、MCP 或 Remote 工具
            X-->>T: 工具结果
            T-->>L: ToolResult
            L-->>A: tool_result / file_changes
            A-->>F: 更新工具卡片与文件列表
        else AskUserQuestion
            L-->>A: confirmation_required
            A-->>F: SSE 确认卡片
            U->>F: 提交选择
            F->>A: REST confirmation response
            A-->>L: 恢复等待中的 AgentLoop
        else delegate_task
            L->>L: 创建子 AgentLoop
            L-->>A: delegation_start / progress / end
            A-->>F: 更新委派卡片
        end
    end

    L-->>C: 最终文本与执行记录
    C->>D: 保存 Assistant 消息、用量和观测数据
    C-->>A: done
    A-->>F: SSE text / done
    F-->>U: 展示完整回复
```

